lbschenkel's Flatpaks

This is a Flatpak repository for some applications that I use and are not available in Flathub for various reasons.

ℹ️ Early adopters: This repository is new and the signing key is short-lived on purpose, read the notice below for details.

Adding the repository

Download and open this file: lbschenkel.flatpakrepo

Or via command-line: 

flatpak remote-add lbschenkel https://lbschenkel.github.io/flatpaks/lbschenkel.flatpakrepo

Applications

The Flatpaks have minimal permissions by default (usually no network and can only read/write to ~/Downloads); if that is not enough you should give more permissions via an override. Check each individual app README for details.

Calculators:
  • Free42 — HP-42 calculator simulator
  • Plus42 — enhanced HP-42 calculator simulator
Infrared / remote controls:
  • IrScrutinizer — powerful program for capturing, generating, analyzing, importing, and exporting of infrared (IR) signals
  • RemoteMaster — upgrade code manager for UEI/JP1 remote controls

Signing keys

This repository is signed with a key that I keep encrypted in my own hardware. Binaries are built via GitHub Actions and I download and sign them manually.

ℹ️ Because this repository is very new, I'm deliberately keeping the signing key short-lived until I'm confident with the whole setup. I will extend the validity in a few weeks. If you add this repository now, and later Flatpak complains that the key has expired, you will need to remove and re-add the repository for Flatpak to take notice of the new validity.
